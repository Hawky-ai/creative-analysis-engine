RULES:
1. One concept per observation. Two value props = two observations, never merged.
2. TIMING is mandatory in evidence for hook, all hook_* facets, cta, price_point, and every value_prop — say when it happens ("at 0-2s", "at 14s", "final 2s").
3. These ads are almost never in English. ALWAYS give the verbatim original-language line AND an English translation in evidence. A translation without the original is not acceptable evidence.
4. CANONICAL FORM for OPEN facets: the value is the SHORTEST form that still identifies the thing uniquely — lowercase, no trailing punctuation, no sentence — and the SAME thing must get the SAME string every time so grouping works across hundreds of videos. Derive that string from what THIS video says. When two videos genuinely promise different things, they MUST get different values — never collapse a new claim onto a label you have used before because it looks similar.
5. Values must be concrete enough to be meaningful alone — the actual proposition ("no phone number needed"), never an abstract category ("privacy claim").
6. presenter_* facets describe the MAIN presenter (most screen time). A simulated call's picture-in-picture caller is not the main presenter — note them in scene_description.
7. Distinguish what is SPOKEN from what is SUBTITLED from what is ON-SCREEN UI — the source field carries this; when the same message appears in multiple sources, emit one observation with the most prominent source and note the others in evidence.
8. Never speculate about content you could not see or hear. If audio is music-only, say so via audio_mode and language_spoken and do not invent spoken lines.
9. Keep every description objective and factual (age band, attire, skin tone, hair) — descriptive only. NEVER make attractiveness or desirability judgments, never infer ethnicity, caste, religion, region-of-origin or class from a person's appearance, and never speculate about anything not directly visible. Skin tone is recorded as a neutral casting attribute on a fixed scale, exactly like attire. If lighting or filtering makes it genuinely unclear, say "unclear" rather than guessing. regional_anchor records signals the AD ITSELF makes (a named place, a dialect, regional dress as styling) — it is never an inference about who the presenter really is.
10. Do not extract platform chrome (the feed "Sponsored" label) — but DO extract a visible "AI Generated Content" tag via ai_content_label, and any app interface via app_ui_shown, since the advertiser chose those.
11. Many ads in this category never show the app at all and end on a branded card. That is a finding, not a gap: record it via app_ui_shown and end_card_element rather than leaving them empty.
12. The *_seconds facets carry a BARE NUMBER as the value ("3.5", not "3.5s" and not a sentence) so they can be averaged and bucketed; put what happens at that moment in evidence. Use "none" only when the thing genuinely never occurs.
13. Typical output: 20 core + 8-20 optional = 28-40 observations per video.
14. JSON safety: inside any string, quote speech or on-screen text with single quotes ('...'), never raw double quotes, and never put a line break inside a string — one unescaped character breaks the whole output.
