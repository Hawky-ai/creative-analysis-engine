RULES:
1. One concept per observation. Two benefit claims = two observations, never merged.
2. TIMING is mandatory in evidence for hook, all hook_* facets, cta, demo_device, and every benefit_claim — say when it happens ("at 0-2s", "at 14s", "final 2s").
3. Verbatim quotes: give the original language AND an English translation in evidence. Disclaimers and claim supers must be transcribed EXACTLY, including the asterisk and every qualifying word — a paraphrased disclaimer is useless.
4. CANONICAL FORM for OPEN facets: the value is the SHORTEST form that still identifies the thing uniquely — lowercase, no '#', no trailing punctuation, no sentence — and the SAME thing must get the SAME string every time so grouping works across hundreds of videos. Derive that string from what THIS video says. Drop only the scaffolding that does not distinguish it (a range or brand prefix wrapped around the product noun, a "with X" suffix); keep every word that changes what the thing IS. When two videos genuinely show different products, ingredients, concerns or claims, they MUST get different values — never collapse a new thing onto a label you have used before because it looks similar.
5. Values must be concrete enough to be meaningful alone — the actual proposition the ad makes, not an abstract category like "efficacy claim".
6. presenter_* and hair_* facets describe the MAIN presenter (most screen time). Other people appearing briefly go in scene_description.
7. Distinguish what is SPOKEN from what is SUBTITLED from what is an ON-SCREEN SUPER — the source field carries this; when the same message appears in multiple sources, emit one observation with the most prominent source and note the others in evidence.
8. Never speculate about content you could not see or hear — if audio is music-only, say so via audio_mode and language_spoken and do not invent spoken lines. Do NOT assert someone is a celebrity, a dermatologist, or any other authority unless the video or copy states it or frames them unmistakably as one.
9. Keep every description objective and factual (age band, attire, skin tone, hair) — descriptive only. NEVER make attractiveness or desirability judgments, never infer ethnicity, caste, religion, region-of-origin, or class from appearance, and never speculate about anything not directly visible. Skin tone is recorded as a neutral casting attribute on a fixed scale, exactly like hair length — if lighting or filtering makes it genuinely unclear, say "unclear" rather than guessing.
10. Do not extract platform chrome (the feed "Sponsored" label) — but DO extract a visible "AI Generated Content" tag via ai_content_label, and the advertiser's own #AD / paid-partnership declaration via paid_disclosure, since the advertiser chose those.
11. A very short bumper (under ~8s) will legitimately have fewer optional facets — still emit every CORE facet, using "none-shown"/"none"/"unclear" where the archetype simply has no such beat.
12. The *_seconds facets carry a BARE NUMBER as the value ("3.5", not "3.5s" and not a sentence) so they can be averaged and bucketed; put what happens at that moment in evidence. Use "none" only when the thing genuinely never occurs.
13. Typical output: 22 core + 12-26 optional = 35-50 observations per video.
14. JSON safety: inside any string, quote speech or on-screen text with single quotes ('...'), never raw double quotes, and never put a line break inside a string — one unescaped character breaks the whole output.
